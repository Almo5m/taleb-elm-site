# ملاحظاتي — موقع طالب علم

الموقع كله ملف واحد بس `index.html` (HTML + CSS + JS جوه بعض)، مفيهوش build ولا npm ولا حاجة —
بترفعه زي ما هو وخلاص.

## الحالة دلوقتي
- [x] عملت هوية بصرية جديدة كاملة للموقع (خلفية فاتحة، بطاقات، ألوان زي التطبيق نفسه بالظبط)
- [x] زرار التحميل بقى بيفتح نافذة (modal) فيها تنويه Play للحماية الأول، وبعدين زرار "حمّل الملف الآن"
- [x] لينك الـ APK بقى في مكان واحد بس في أول الـ `<script>` — سطر `const APK_URL = ...`
- [x] واتساب وفيسبوك والإيميل متحطين في الفوتر وقسم الدعم
- [x] مفيش تليجرام ولا إنستجرام في الموقع
- [x] كل الصور والسكرين شوتات مرفوعة جوه `assets/`
- [ ] لسه هنشره على GitHub Pages (بعد التصميم الجديد)
- [ ] لسه مش متنشور على Google Play (ده اللي قسم الدعم بيجمّع فلوس عشانه)

## لو عايز أحدّث لينك الـ APK
افتح `index.html`، دور على السطر ده قرب آخر الملف (جوه `<script>`):
```js
const APK_URL = "ضع_رابط_تحميل_الـ_APK_هنا";
```
غيّر القيمة بلينك الـ release الجديد من GitHub، وخلاص — كل زراير التحميل في الموقع
(فوق، ونص الصفحة، وقسم الـ CTA) هتستخدم نفس اللينك تلقائي، مش محتاج أغيّره في أكتر من مكان.

## إزاي شغالة نافذة التحذير
أي زرار "حمّل التطبيق" في الموقع (مش لينك مباشر) بيفتح نافذة فيها صورة رسالة "Play للحماية"
وخطوتين الحل، وبعدين زرار "حمّل الملف الآن" هو اللي فعليًا بيودي على `APK_URL`. يعني حد
يقدر يشوف الملف ينزل من غير ما يقرا التنويه الأول.

## الملفات اللي لازم أرفعها كلها مع بعض (مش index.html بس)
`favicon-32.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `og-image.png`
ومجلد `assets/` بالكامل — فيه `app-icon.png`، `assets/screenshots/` (السكرين شوتات الحقيقية)،
و `assets/play-protect-warning.webp` (صورة رسالة "Play للحماية" المستخدمة في التنويه والنافذة).

## نشر على GitHub Pages
في الريبو: Settings → Pages → اختار الفرع `main` والمجلد `/root` (أو `/`) → Save.
هياخدلك شوية دقايق وبعدين يديني رابط زي `username.github.io/repo-name`.

## تتبّع الزوار (Supabase)
الموقع فيه تتبّع بسيط وخاص لأربع أحداث: زيارة الصفحة، وصول المستخدم لمرحلة التحميل
(فتح نافذة تحذير Play للحماية)، التحميل الفعلي، ومتابعة قناة الواتساب.

**الإعداد (مرة واحدة بس):**
1. شغّل ملف `analytics/supabase-setup.sql` كامل في Supabase Dashboard → SQL Editor.
   غيّر كلمة `غيّر_الباسورد_ده_CHANGE_ME` الموجودة مرتين جوه الملف لباسورد من عندك قبل ما تشغّله.
2. في `index.html`، حط بيانات مشروعك في أول الـ `<script>`:
   ```js
   const SUPABASE_URL = "...";
   const SUPABASE_ANON_KEY = "...";
   ```
3. نفس الاتنين لازم يتحطّوا كمان في `analytics/dashboard-x7k29.html`.

**عشان تشوف الأرقام:** افتح `analytics/dashboard-x7k29.html` وادخل بالباسورد اللي حطيته
في الـ SQL. الصفحة دي مش متلينكة من أي مكان في الموقع ومحمية بباسورد بيتشيك عليه من جوه
Supabase نفسه (function بـ `security definer`)، يعني حتى لو حد لقط مفتاح الـ anon من كود
الموقع (وهو أصلًا ظاهر لأي حد بيفتح الموقع بالتصميم) مش هيقدر يقرا بيانات الزوار من غيره.
سيب اسم الملف زي ما هو ومتحطهوش في أي لينك أو نافيجيشن.

## نظام التقييمات (Supabase)
قسم "آراء الطلاب" بيسمح لأي زائر يبعت تقييم (اسم + نجوم + تعليق اختياري)، لكن التقييم
مابيظهرش للعامة إلا بعد ما توافق عليه من لوحة الإحصائيات الخاصة.

**الإعداد (مرة واحدة بس، بعد إعداد التتبّع فوق):**
1. شغّل ملف `analytics/supabase-setup-reviews.sql` كامل في SQL Editor. ملف منفصل تمامًا
   عن تتبّع الزوار، وميأثرش على جدول `site_events` ولا بياناته.
2. غيّر كلمة `غيّر_الباسورد_ده_CHANGE_ME` الموجودة مرتين جوه الملف — استخدم **نفس الباسورد**
   اللي حطيته في `supabase-setup.sql`، عشان توافق على التقييمات من نفس لوحة الإحصائيات
   بنفس الباسورد.
3. بيانات Supabase (`SUPABASE_URL` و`SUPABASE_ANON_KEY`) نفس المتغيرات اللي حطيتها بالفعل
   في `index.html` و`dashboard-x7k29.html`، مفيش حاجة زيادة تحطها هنا.

**إزاي تراجع التقييمات:** في `dashboard-x7k29.html`، دوس على تبويب "⭐ التقييمات" فوق —
هتلاقي عدّاد بيوريك عدد التقييمات المحتاجة مراجعة، وتقدر "تنشر" أو "تحذف" كل تقييم لوحده.
بعد النشر التقييم بيظهر فورًا في قسم "آراء الطلاب" بالموقع.

**تحديث "آخر التحديثات":** مع كل نسخة جديدة من التطبيق، عدّل مصفوفة `APP_UPDATES` في أول
`<script>` بتاع `index.html` — ضيف عنصر جديد فوق القايمة وسيب `latest: true` عليه بس،
وشيلها من اللي قبله.

## حاجات أفتكرها
- الخطوط بتتحمل أونلاين من Google Fonts، فمحتاج نت عادي وقت فتح الصفحة بس.
- الموقع static بالكامل، وبيبعت بس أحداث تتبّع مجهولة (بدون أي بيانات شخصية) لـ Supabase
  لو حطيت بياناته، وبيتجاهلها تلقائي لو سبتها فاضية.
- الهوية الجديدة مبنية على شكل التطبيق نفسه بالظبط (خلفية فاتحة، بطاقات بيضا، أخضر أساسي،
  كمان الألوان الفاتحة لكل مادة زي ما هي في شاشة "المواد") — عشان لما حد يشوف الموقع بعدين
  يفتح التطبيق يحس إنه نفس الحاجة، مش حاجتين مختلفين.
